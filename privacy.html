PowerBlock Privacy Policy

Last Updated: August 20, 2025

Introduction

PowerBlock is an open-source ad blocker browser extension designed to enhance your browsing experience by blocking advertisements, tracking scripts, and malicious overlays. This privacy policy explains our practices regarding data collection, use, and protection.

Data Collection

PowerBlock is designed with privacy as a core principle. We do not collect, store, or transmit any personal information to external servers or third parties. All data processed by PowerBlock remains on your device.

Data We Do Not Collect

  • Personal identification information (name, email, address, etc.)
  • Browsing history or visited URLs
  • Search queries or form data
  • Device identifiers or IP addresses
  • Cookies or tracking identifiers
  • Any personally identifiable information

Local Data Storage

PowerBlock stores the following information locally on your device using the browser’s storage API:

  • User Preferences: ad blocking settings, feature toggles (overlay removal, click hijacking prevention), security settings (clickjacking protection, hidden overlay detection), sensitivity levels for security features
  • Whitelisted Domains: list of websites where ad blocking is disabled
  • Temporary Counters: number of ads blocked per tab (reset when tab is closed), security event logs (limited to 50 recent events, automatically rotated)

All stored data is used solely for the extension’s functionality and is never transmitted outside your device.

Data Usage

All data processed by PowerBlock is used exclusively for:

  • Blocking advertisements and tracking scripts as requested by the user
  • Maintaining user preferences across browser sessions
  • Providing statistics on blocked content
  • Detecting and preventing malicious overlays and clickjacking attempts

Security Features Data

Our advanced security features collect minimal diagnostic information locally:

  • Clickjacking Protection: logs when frame‑busting techniques are activated
  • Hidden Overlay Detection: records basic information about blocked overlays (element type, position)
  • Security Event Logs: maintains a rotating log of security events (maximum 50 entries)

All security data is stored locally and never transmitted.

Third-Party Services

PowerBlock does not integrate with or rely on any third-party analytics, advertising, or tracking services. We do not share any data with external entities.

Filter Lists

PowerBlock uses publicly available filter lists (e.g., EasyList, uBlock Origin filters) for ad blocking. These lists are:

  • Downloaded and processed locally
  • Not modified or transmitted
  • Used solely for determining which requests to block

Data Sharing

We do not share, sell, rent, or trade any data with third parties. No information is transmitted from your device when using PowerBlock.

Data Retention

All data is stored locally and persists only as long as:

  • The extension is installed
  • Browser data is not cleared
  • User does not manually reset settings

Security logs are automatically rotated to maintain only the 50 most recent events.

Your Rights

As no personal data is collected, there are no special procedures needed for data access, correction, or deletion. To remove all locally stored data:

  1. Uninstall the extension
  2. Clear browser data for the extension
  3. Manually reset settings through the popup interface

Changes to This Policy

We may update this privacy policy to reflect changes in our practices or for legal compliance. Significant changes will be communicated through extension updates.

Contact Information

For questions about this privacy policy, please open an issue on our GitHub repository or contact the development team through the extension’s support channels.

Open Source

PowerBlock is open-source software. You can review our code at any time to verify our privacy practices.
